# Pico — AI Desktop Companion

**A product by [Vaelix](https://www.vaelix.in)**

Pico is an emotionally responsive AI desktop companion that sees, hears, and reacts like a pet. It communicates not through words, but through expressive sounds, animated eyes, and lifelike head movements.

> **Status:** Currently in active development at Vaelix.

## About

This is the official website for **Pico**, built with Next.js, Tailwind CSS, and Framer Motion. The website showcases Pico's capabilities, technology, and vision.
